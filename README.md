# Chiptuning.gudermes

Сайт чип-тюнинга и автодиагностики в Гудермесе.

Next.js + TypeScript. Сайт настроен на статическую сборку (`output: "export"`), поэтому его можно размещать даже на обычном статическом хостинге.

## Запуск

```bash
npm install
npm run dev
```

Открыть: http://localhost:3000

## Production

```bash
npm run build
```

После `npm run build` готовый статический сайт находится в папке `out/`.

## Деплой

Можно загрузить содержимое `out/` на обычный веб-хостинг. Node.js на сервере для production не требуется.

## Важно перед публикацией

1. Заменить `https://chip-gudermes.ru` на фактический домен, если будет выбран другой.
2. Уточнить настоящее название сервиса.
3. Добавить реальные часы работы.
4. Добавить реальные фотографии сервиса и автомобилей.
5. Добавить цены, если брат хочет показывать их на сайте.
6. Создать/заполнить карточки в Яндекс Бизнес, 2ГИС и Google Business Profile.
7. После публикации добавить сайт в Яндекс Вебмастер и Google Search Console.
